01 · SCENARIO

The rules create a real choice: contest valuable loot, fight for an opponent's carried value, or leave safely with what you have.

Raid
1v1 · 75 seconds
Combat
100 HP · 20 damage · 30 rounds
Inventory
3 slots · loot worth 10 / 25 / 50
Extraction
2 zones · opens at 30s · hold for 3s
Death
Unbanked loot becomes a collectible cache
Objective
Only successfully extracted value counts

02 · METHOD

Capability is learned once. Style is added with small bounded residual adapters over the same frozen Strong Actor.

Scripted Teacher→ Behavioral Cloning→ Recurrent PPO→ Frozen Strong Actor→ Residual Style Adapter

Fair observation. Public inference uses only first-person pixels and the player's own public state. Privileged Critic features and reward ledgers are training-only.

03 · STYLES

Each style starts from the same frozen Strong Bot. The videos are validation-selected product evidence, not benchmark claims.

Strong

Priority · complete the task

Balances loot, combat risk, and extraction timing.

Watch: high-value loot becomes banked value.

Aggressive

Priority · convert useful fights

Favors combat with sufficient resources, then converts kills into value.

Watch: hit → kill → corpse cache → extraction.

Defensive

Priority · protect carried value

Uses a learned residual plus a low-health carried-value guardrail.

Watch: stops chasing, creates distance, leaves alive.

Explorer

Priority · improve route and inventory

Visits useful loot regions and replaces low-value items.

Watch: broader search → backpack upgrade → extraction.
