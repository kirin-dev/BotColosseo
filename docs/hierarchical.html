Training route & observation boundary

Command Teacher + BC → conservative executor PPO → frozen-executor cross-play and strategic responses → conditional distillation → random-segment style/difficulty PPO. The later joint-trained candidate was not selected.

The high Actor normally replans every eight low decisions; public events can trigger earlier replanning. The executor acts every four engine tics. Privileged state is used for training supervision and Critic targets, not deployment. Distillation includes explicit preference priors; this is not proof of an unconstrained best response.

04 · RESULTS

One model. Distinct preferences. Adjustable difficulty.

Development results; not proof of generalization or switching benefits.

Evaluation protocol & limitations

The 96 switching episodes reuse 16 layout/role cases; matched seeds do not reproduce identical histories. Style bars use decisions 88–160 after the first switch. Repeated orders are averaged within a case, then across cases. Later phases include carryover and early-ending effects. The policy, executor, opponent and Hard difficulty are fixed across all six orders.

Difficulty results use 192 full games over eight layouts, both roles and four styles with one frozen policy. Positive-value episodes: 67.19% / 81.25% / 85.94%. Adjacent aggregate banked-value differences are positive under paired layout bootstrap; extraction including empty-handed exits is 90.63% / 90.63% / 87.50%. This is not universal difficulty calibration.

All four videos use one selected deployment combination, but different seeds and roles. The live clip changes both style and difficulty. Reliable PSRO response gains and formal executor promotion were not established. Clip identities · Candidate selection

Population learning: results and limitations
Fixed strategy
Mean banked value 28.6 · positive banked 78.1%
Uniform population
Mean banked value 35.9 · positive banked 75.0%
Meta-strategy
Mean banked value 32.7 · positive banked 81.3%

32 games per method across eight separate layouts, both roles and two repeats; each method faces the same sampled uniform-population opponents. All paired 95% layout-bootstrap payoff-difference intervals include zero. This comparison does not establish a reliable gain from meta-strategy selection.

Changing the shared executor changes the game: all payoff cells were recomputed. The resulting restricted-game solution mixes strategies, with measured matrix regret zero. Across 200 layout-cluster bootstrap resamples, mixture weights vary substantially; the point solution is not a stable population ranking. Independent response validation did not establish a gain, and this is not a claim of global Nash convergence. Executor command-retention checks were mixed, so the new version remains a research candidate.

Earlier conditional PPO follow-up

A 25k-decision task fine-tune changed mean banked value from 29.22 to 38.44 and positive-bank episodes from 29 to 31 in a paired 32-game, four-layout development screen. The executor stayed frozen with a distilled high-Actor KL reference; this is not generalization evidence.
